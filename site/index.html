原理

每一行都有出处

出处分四种。把鼠标放到左边任意一种上，右边会标出对应的行。

src/analyze.ts
只算真写进去的被拒绝、写失败的编辑不算。
推断可以关掉严格、标准、宽松三档。严格档只认日志和提交里写明的。
只写 AI署名里只有工具和模型，不写人名。

开始用

三种用法

命令行，或者交给 agent

在仓库里跑一条命令就行。仓库里带了 skill，Claude Code、Codex 这些 agent 也能替你跑，公开任何东西之前会先问你。

$ npx creditia analyze $ npx creditia export \ --piece roll --style cinema $ npx creditia publish

放进 README

把 credits.json 提交进仓库，GitHub Action 会在每次推送后更新徽章、CREDITS.md 和署名页。

your-project
uses: WroughtMind/creditia@main

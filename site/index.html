风格

同一份数据，十六种样子

每种风格不只是换颜色，排版也跟着变：古籍是竖排的，赛博是一块块面板，漫画是能力图。下面是同一个示例项目，选一种看看，鼠标放在图上能看到每一块的数字。

画册

片尾字幕、小票、统计图

署名榜之外，还有十几种作品。都能导出成图片、PDF、动图，或者一个鼠标放上去能看数字的网页。

怎么算的

每一行都有出处

出处分四种。把鼠标放在左边的一种上，看看是哪几行。都在你的电脑上算，不上传代码，也不调用任何模型。

src/analyze.ts

人的工作没法按行数算，所以单独写几个数：发给 AI 多少条消息、review 多少次、人写了多少行；名字默认不出现。被拒绝、写失败的编辑不算。完整的规则和已知的局限 →

用法

在仓库里跑一下

# 分析（第一次会下载对应平台的分析程序）
$ npx creditia analyze

# 出图：作品、风格、格式随便挑
$ npx creditia export --piece roll \
    --style cinema --format gif

# 放到 GitHub 上，每次推送自动更新
$ npx creditia publish
让 agent 来做

仓库里带了一份 skill。Claude Code、Codex 这些 agent 会一步步来，公开任何内容之前先问你。

App

把所有作品摆成一面墙：切项目、切风格、悬停看细节、拖到角落导出。目前是没有签名的 macOS 版。

GitHub Action

用仓库里的 credits.json 生成徽章、CREDITS.md 和署名页，每次推送后自动更新。

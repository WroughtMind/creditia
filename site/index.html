creditia

你的代码，
是哪些 AI 写的

把 agent 的日志和 git 历史逐行对上，算出每个工具、每个模型写了多少，做成片尾字幕。全在本地。

$npx creditia analyze

同一份署名，二十六种样子

导出成图片、PDF、动图、网页、Markdown

每一行，都有出处

对不上的记为未确认。全在本地，不调用模型。

四种用法

$ npx creditia analyze Claude Code 59.3% · Codex 27.6% · Cursor 6.7% · Kimi 3.1% · Grok 1.3% $ npx creditia export --piece roll --variant slate \ --format png --out credits.png → credits.png $ npx creditia doc → CREDITS.md
# .github/workflows/credits.yml on: { push: { branches: [main] } } jobs: credits: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: WroughtMind/creditia@main with: badge: assets/credits-badge.svg doc: CREDITS.md

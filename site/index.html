creditia

你的代码，
是哪些 AI 写的

creditia 把 Claude Code、Codex、Cursor 这些工具的日志和 git 历史逐行对上，算出每个工具、每个模型写了多少，再做成一卷片尾字幕。全在你的电脑上算。

$npx creditia analyze

示例项目，数字是编的 · 鼠标放上去暂停

同一份署名，
二十六种样子

十五种原版主题，加上水墨、浮世绘、古籍、漫画、赛博等十一种新风格。署名榜、片尾字幕、小票、徽章、统计图，都能导出成图片、PDF 或网页。

每一行，
都有出处

对得上工具日志的算数，提交里写明了的算数，对不上的记为「未确认」，不算到谁头上。被拒绝、写失败的编辑不算。不上传代码，不调用模型。

在仓库里
跑一下

第一次运行会下载对应平台的分析程序。也可以交给 agent：仓库里带了 skill，公开任何东西之前它会先问你。

# 分析这个仓库 $ npx creditia analyze # 出一张片尾字幕：作品、风格、版式、格式都能选 $ npx creditia export --piece roll --style cinema --variant slate --format png # 把档案放进仓库，GitHub Action 会在每次推送后更新徽章和署名页 $ npx creditia publish
读得懂这些工具的日志
放进 README →徽章、CREDITS.md 和署名页，每次推送自动更新。 App →所有作品摆成一面墙，切项目、切风格，拖到角落导出。目前是未签名的 macOS 版。 规则和局限 →每种出处怎么认、严格和宽松的区别、目前还认不出的情况。

## 已实现的改动

### 材质与内容分工

`packages/render/src/material-motion.ts`：作品决定哪些内容一起出现、先后次序和边界，材质决定如何出现。

- `materialEnter`：完整文字、标记、纸面、数据进入；k=0 仍执行排版回调，隐藏并清理命中区；k=1 直接原始绘制，无额外容器。
- `materialReveal`：纯图形边界，文字不应走裁切。手稿已全局保护；终端字符条由调用方保护。
- `materialOrder`：按真实行/列位置决定铺版次序。偶数中心距离已归一化，避免中心两列开始过晚。
- data 角色不平移/旋转数据；paper 不叠加内容滤镜和装饰基线。
- 内容小字不做形态膨胀；真实图片发现 resvg 很小的非零半径仍会吞字腔。膨胀仅保留几何标记，普通文字只用轻微模糊/明暗。
- 局部滤镜限制在内容边界加余量，避免每一行都分配整张长卷。

动作方向包含精确对齐、暗面亮边、玻璃聚焦、胶片曝光、影院开幕、杂志基线、报纸压印、节目单对开、颁奖揭幕、单色轮廓、海报落版、终端输出、CRT 扫描余辉、霓虹通电、街机整格、落墨、套版、木刻、古典中轴、魔典描记、书稿逐行、柔彩成对、剪纸落位、夏日顺势、漫画分镜、赛博分区。应继续审视这些机制在各个形态中是否真的合适，不能仅依据这个表认为设计完成。

### 原版主题

`classic/motion.ts` 的显式内容组动作，`classic/forms.ts` 的版式标注和原生徽章，`classic/art.ts` 在排版后采样。

修复过：环形图矩形切边、终端像素被三角扫窗切碎、纸面随文字曝光变灰、重复 filterUnits、霓虹面积 pathLength 在 resvg 不生效。原版环形按圆弧自身显现；霓虹面积按时间轴点亮。

### 长卷：已推翻一次性能回退方案

曾尝试每帧重画长卷并让段落 materialEnter，独立审查发现 App 根本没用该路径，而且 320px GIF 从约 9.3 秒退化到 102.6 秒。该方案已删除，不能再恢复。

现在 `scroll-motion.ts` 生成真实段落/行距决定的共享时间线：投影类连续、纸张按章节停驻、字符屏按实际行距进纸。26 风格和内部别名均显式归类。App 的已有预览图 WAAPI、GIF 裁图、HTML CSS 使用同一时间线；GIF 只栅格化一次。

注意：当前 export.ts 对混用多个不同 crop.svg 的 frames 抛错。这是最后一轮新增的限制，**还没有由主 agent 评估是否需要保留**；请审查是否是不必要的防御约束。保持公共导出行为合理，不为性能契约强行破坏其他合法调用。

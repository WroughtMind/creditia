# #116 动作形式复查（2026-10-30）

用户明确要求：风格与产物的差异要体现在可见形式和内容编排上，不能只换时长、延迟、缓动，再把它称为独立适配。上一轮的 1523 组合正确性和代表播放检查不能证明每个组合均已完成独立设计；本轮据此重新审查并修改。

## 找到并改掉的重复

| 内容 | 原薄弱点 | 现在的动作单位与形式 |
| --- | --- | --- |
| 材质图形 | 浮世绘、报纸、胶片共用条带扫窗，只改变条数 | 浮世绘由作品交出实际色版；报纸网线压印；胶片在连续曝光中形成局部颗粒密度；木刻沿刀痕填实，魔典交叉刻痕成形 |
| 星号 | 部分印刷风格仍是通用逐瓣淡入 | 胶片、报纸、木刻在完整瓣形内成像；魔典沿实际瓣轮廓描记；草木围绕真实花心舒展；水墨保留原逐瓣有机生长，剪纸保持整瓣落位 |
| 原生环图 | 玻璃、胶片只换透明度曲线；多数共享沿弧增量 | 玻璃沿环厚度凝结；单色内外轮廓合版；报纸网线压印；胶片各弧从两端曝光。最终弧角、半径和比例不变 |
| 领奖台 | 台座与姓名整组套 data 入场，多个风格退化成淡入 | 台座完整边界与内部材质分开，随后出现完整名次、姓名和真值；不采用切出台顶斜坡或悬浮块的窗口 |
| 分享图与徽章 | 份额段逐个扫出，紧凑徽章沿用长内容编排 | 份额图保持所有段真实宽度；分享图组织标题、份额、对应图例；徽章按紧凑签名整体形成，不裁文字 |
| HUD、分组榜、角色卡 | 文字先于面板、层级未参与、整串卡片套同一动作 | HUD 先面板后完整读数组；分组榜按工具再模型；角色卡与人员组分层，两列卡按真实行成对进入 |
| 河流与会话 | 多数河流共享中线增高；会话被横向扫窗截成假结束时刻 | 水墨保留逐周中线；印刷按真实贡献色带，光学按完整河带；杂志按真实周列落版；会话按真实开始时间出现完整起止区间 |
| 柔彩的数据图 | 通用双圆泡割裂时间序列与真实份额 | 河带、模块条、版本列按实际内容成对出现；不添加无数据含义的气泡 |
| 代码地图 | 全风格整行阈值上色再套全图 data 淡入 | 拼贴/排版以真实文件为单位，报纸按版面栏，浮世绘按归属色版，终端/手稿按完整行，图形保留真实归属与确定的笔画 |
| 单位格与强度格 | 单位格的 data 入口抹掉运动；原生作息格动画 opacity 改变数据强度 | 单位格保持面积，以完整刚体入位；强度格始终使用最终强度，屏幕风格保留寻址/扫描/接通；字符条只显示完整字符与完整数值组 |

## 以实际画面否决的方案

中间帧和 WebKit 完整播放发现并否决了：热力格机械选框装饰、柔彩河流的双圆泡、过强的胶片盐点、节目单角色卡对角入场、报纸纹样在缩小后消失、木刻/魔典纹样留洞直到终帧才补齐。代码分支不同、像素摘要不同、时间线结束都没有被当成审美通过。

## 共享边界

这不是“1523 个组合互不复用、全部从零独创”的声明。普通名单、短签名和小尺寸强度格仍共享各自的基础语义；柱形守基线、圆环按真实弧形、完整文字组、统一滚动时间线也应共享。不能把这些基础规则或同一个入场动作仅换参数，作为某组合已独立设计的证据。

自动矩阵负责全范围的真实栅格、有效几何、可见变化和最终静态一致；视觉报告列出真正打开查看的样本；WebKit 报告分别记录自然完整播放、控件与审美发现。剩余 Mac 原生真机性能和最终用户观感仍需单独验收。

本轮生成证据使用独立目录：`strict-pieces/`、`classic-refinement/`、`visual-review/strict-*/`、`material-independent/`、`material-matrix-refinement-final/`、`webkit-refinement/`、`export-refinement/`。历史首轮结果保留，最终报告用源码差异摘要和预览 SHA 标识版本。

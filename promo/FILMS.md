# creditia 宣传片：两支

两支都要做到：
- 一眼看懂它做什么：每一行代码，都标出是哪个 AI 写的；算出来，做成署名。
- 只用真东西：真的代码行、真的份额（样例项目 catnap）、真的作品图（26 种风格都是 `creditia export` 导出来的）。
- 不靠文字讲：画面里只出现产品名、工具名、模型名、数字、网址和命令。
- 一个连续的空间，镜头一直在动，不切卡片。
- 配乐跟着画面里发生的事走，不卡鼓点。

上一版的问题，这两支都要避开：
- 抽象比喻太多（丝线、灯下的尘），看完不知道产品是干嘛的；
- 风格展示是一张接一张地换，像放 PPT。

新的标志是五瓣星号 `*`。排版里 `*` 就是脚注，意思是「出处在这儿」。两支片子都围着它讲。

---

## 一、短片《脚注》 · 约 22 秒

一句话：**每一行代码都有一个脚注。**

| 时间 | 画面 | 声音 |
|---|---|---|
| 0–0.6 | 暗场里一个橙色光标在闪 | 静 |
| 0.7–2.1 | 光标一小块一小块地写出一行真代码（模型按 token 吐字）：`export function pickSpot(cat: Cat, room: Room) {` | 笔尖一样的颗粒声，很轻 |
| 2.1 | 行尾弹出一个橙色的小 `*` | 一声钢琴（Claude 的音） |
| 2.4–3.9 | 下面一条细线，脚注浮出：`* Claude Code · Claude Opus 5.5` | 余音 |
| 3.6–8 | 镜头往后拉：同一个文件里其余的行被各自颜色的光标同时写出来，每写完一行就冒出它的 `*`（Codex 绿、Cursor 蓝、Kimi 紫、Grok 黄；没认出来的行没有星号）；再往后拉，整个仓库从这个文件往外一圈圈写出来，亮起成千上万颗小 `*` | 每个工具一个音，越来越密，变成玻璃雨点和细雨 |
| 8–12.5 | 所有的 `*` 离开纸面，按颜色流向中心，长成这个项目自己的大星号：瓣长就是份额。瓣尖浮出 `Claude Code 50.9%`、`Codex 30.8%`… | 雨点收拢成一个和弦 |
| 12–16 | 星号缩小，上方浮出一叠牌，像一手牌那样捻开成约 200° 的扇面：26 种风格的同一张署名卡。一道波从左到右把每张牌依次抬起来 | 往上走的琶音；每张牌一声玻璃音，跟着波往上走 |
| 16.2–18.5 | 扇面合拢成一叠，一叠收回星号；星号的瓣变成等长，就是标志 | 往回收的下行 |
| 18.5–22.3 | 星号让到左边，右边写出 `creditia`，下面 `npx creditia analyze` | 最后一个音落下，淡出 |

为什么这样展示风格：26 张同时摊开，一眼就看到有多少种样子，用不着一张接一张地翻。扇面就从那颗星号上长出来，又收回去，标志、数据、作品连在一起，是一个动作，没有切换。

规格：1920×1080 母版，60 fps；同一套代码出 1080×1920 竖版（`?aspect=9:16`），给社交平台用。

## 二、长片《片尾字幕》 · 约 77 秒

一句话：**一个项目的 141 天，最后落成一份片尾字幕。**

全片是一个空间：一块暗色的地面，代码地图、证据、署名卡、看样台、片尾字幕都在这块地上；开头的终端竖在它前方的半空。镜头一路连续地走，没有切换。

| 时间 | 画面 | 声音 |
|---|---|---|
| 0–7.5 | 暗场里一个终端。敲 `npx creditia analyze`，出三行真结果（`catnap: 734 commits …`、各工具份额、`wrote .creditia/credits.json`）；再敲 `npx creditia fetch`，印出那张名片（和 CLI 同一个函数生成的五条份额条） | 几乎无声，只有按键；名片印出来时钢琴落一个和弦 |
| 7.5–10.4 | 镜头推近，钻进 Claude Code 那一格进度条，穿过去，低头看见下面的地面 | 气流升起来，穿过时一个低音 |
| 10.5–22.7 | catnap 的代码地图：10 个真文件、真行数、各工具真份额，在 141 天里一段段写出来，有的段落先被一个工具写、后来被另一个改写（颜色一闪换掉）。远端一条时间轴：日期在走，734 个提交按每天写的量一颗颗落下，发版那天标出 `v0.1.0` `v0.2.0` `v0.3.0` | 细雨一样的颗粒声，跟着每天写的量起落；发版那天一声玻璃 |
| 22.7–35 | 镜头落到 `src/spots/pick.ts`，代码变回真字。一行行标出处：日志里对得上的（实心星号，一根线连到 Claude Code 会话记录里同样的那一行）、提交里写明的（半透明星号，线连到提交信息里的 `Creditia-Harness` trailer）、推断的（很淡的星号，没有线）、未确认的（灰色虚线框，没有星号）。镜头斜过去，面板浮在半空的层次出来 | 每标一行响一个音：对得上的最清楚，推断的很闷，未确认的没有音高 |
| 35–43 | 各行的颜色化成小星号，连同整个仓库里别的行，流进六条份额条；份额条的位置、长短就是署名卡上那六条，卡片浮出来，正好接上 | 往上走的琶音，落满时和弦铺开 |
| 43–58 | 灯亮起来：署名卡原来躺在一张台子上，四周摊着同一份署名的 26 种样子（26 种风格，件件是不同的作品：片尾字幕、收据、日历、代码地图……）。镜头压低贴着台面横移，焦点在作品间换，再升起来看全。霓虹那件在闪，CRT 那件的亮带往下走，玻璃那件有一道反光扫过 | 最舒展的一段，钢琴慢慢唱一句 |
| 58–70.4 | 灯暗下去，台面上滚起 catnap 真正的片尾字幕：`creditia export --piece roll --style cinema` 的三种版式（出品、各工具各模型和行数、THE END）接成一条 | 弦乐整个铺开，低音进来 |
| 70.4–77 | THE END 停在正中，字淡去，下面那五颗金色菱形聚拢、转向、换成五个工具的颜色，长成星号的五瓣；星号让到左边，`creditia`，下面是网址 | THE END 落在主和弦上；五个工具的音各响一下；最后只剩一个音 |

人写的行在地图上不上色，也不出现在任何名字、数字里（同产品的口径）。

## 怎么渲染（在你的 Mac 上）

```bash
cd promo && npm install && npm i playwright && npx playwright install chromium && cd ..
promo/short/build.sh              # 短片：作品图 + 画面 + 配乐 + 合成 → promo/.build/short/creditia-short.mp4
promo/long/build.sh               # 长片 → promo/.build/long/creditia-long.mp4
```

- 需要 node 22+、python3（numpy、scipy、pillow）、ffmpeg、playwright（默认找 `promo/node_modules`，也可以用 `PLAYWRIGHT_DIR` 指向别的目录）。作品图用的是仓库里的 CLI，片子里的字体取自 packages/render，所以先在 `packages/render` 和 `packages/cli` 里各 `npm install` 一次。
- macOS 上 `render.mjs` 用 ANGLE Metal 走显卡；别的系统没有显卡就回落到 SwiftShader（很慢）。
- 竖版：`ASPECT=9:16 promo/short/build.sh`（只有短片有竖版；长片的镜头要穿过终端、贴着台面走，只做横版）。
- 只看几帧：`node promo/short/render.mjs stills 2.4,9,14`、`node promo/long/render.mjs stills 4,16,30`（文件在 `promo/.build/<short|long>/stills`）；快速预览：`FPS=30 SCALE=0.5 promo/short/build.sh`。
- 分段渲染，断了重跑会接着来；改了画面要先删掉 `promo/.build/short/seg`。
